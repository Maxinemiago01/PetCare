# Android APK and download QR

The app uses Capacitor to package the Angular build as an Android app. Supabase remains the backend.

## Download

- [Download petcare.apk](https://github.com/Maxinemiago01/PetCare/releases/download/android-demo/petcare.apk)
- [Android demo release](https://github.com/Maxinemiago01/PetCare/releases/tag/android-demo)

![Scan to download Petcare](../downloads/petcare-download-qr.png)

The APK and QR are published. The [verified build](https://github.com/Maxinemiago01/PetCare/actions/runs/42266968593) completed successfully on November 7, 2026 (Asia/Manila).

On an Android phone, scan the QR, download the APK, open it, and allow installation from the browser when Android asks. Then install Petcare and create an account. The app needs internet to use Supabase.

## GitHub build

The workflow is `.github/workflows/android.yml`. Pushing to `main` or `master` starts it automatically. You can also open **Actions > Build Android APK > Run workflow**.

After the build finishes, open that workflow run's **Summary** page. The job summary displays the download QR image and a clickable APK link. The APK and QR image are also included in the `petcare-android` artifact and the Android demo release.

It installs Node 24, Java 21, and Android SDK 36; builds the Angular app; copies it into Android; builds a signed debug APK; generates the QR; and uploads both files to the **Petcare Android demo** release. No extra GitHub secrets are required.

The repository must be public for classmates to download without signing into GitHub. The workflow's `contents: write` permission allows it to publish release files. If repository policy blocks this, enable read and write workflow permissions under **Settings > Actions > General**.

The download uses the fixed `android-demo` release and `petcare.apk` filename. Later builds replace that APK, so the same QR continues to work. Build numbers increase automatically with the GitHub run number.

## Files to understand

| File                                | Purpose                                                  |
| ----------------------------------- | -------------------------------------------------------- |
| `.github/workflows/android.yml`     | Instructions GitHub follows to build and publish         |
| `capacitor.config.ts`               | App name, Android package ID, and the `www` build folder |
| `android/`                          | Standard native Android project generated by Capacitor   |
| `scripts/generate-download-qr.mjs`  | Creates the QR from the GitHub repository name           |
| `downloads/petcare-download-qr.png` | QR image to share or print                               |
| `downloads/download-url.txt`        | Exact APK URL encoded in the QR                          |

The native icon and splash reuse the provided paw image. The viewport uses `contain` so Capacitor keeps content clear of Android system bars.

## Local commands

```powershell
npm run android:sync
npm run android:open
```

The first command builds Angular and copies it into Android. The second opens Android Studio, which must be installed separately to build on this computer. Use Android Studio 2025.2.1 or newer with Java 21 and Android SDK 36. The generated app supports Android 7.0 (API 24) and newer.

To recreate the QR from the current Git remote:

```powershell
npm run android:qr
```

Or specify a repository explicitly:

```powershell
npm run android:qr -- https://github.com/Maxinemiago01/PetCare
```

## Demo signing

Gradle automatically signs this classroom APK with a debug key on the build runner. Signing keys are excluded from Git. A Play Store release needs its own private release signing configuration.

Each clean build runner can use a different debug key. If Android says an existing version has an incompatible signature, uninstall that older copy before installing the new one. Uninstalling clears its local sign-in session; Supabase records stay under the account.
